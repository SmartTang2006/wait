# 诗词雅趣 · 古诗词知识问答

一款**单文件、无需联网**的古诗词知识问答小工具。整个应用就是一个 HTML 文件，双击即可使用，带你走进古典之美。

## 快速开始

1. 用浏览器（Chrome / Edge / Firefox / Safari 等）打开 `古诗词问答.html`，或直接**双击**该文件。
2. 在封面页点击 **「开 始」** 进入主界面。
3. 顶部导航栏切换不同的题型，开始挑战。

> 无需安装任何软件，无需联网，无需服务器，打开即用。

## 界面总览

- **封面页**：进入应用后先看到水墨风格的封面，点「开 始」进入。
- **返回封面**：主界面右上角的 **「🏠 封面」** 按钮，可随时回到封面页。
- **导航栏**：顶部有五个标签页，对应五种题型，点击即可切换。

## 五种题型

### 🎯 闯关答题（选择题）

- 看题目选答案，答对得分。
- 可选 **「全部 / 基础 / 进阶」** 难度：
  - **基础**：课本常见名篇与常识；
  - **进阶**：作者称号、名句出处、典故人物、诗人并称等。
- 每道题有 4 个选项（**选项顺序每次自动打乱**）。
- 答完立即显示对错：正确选项标绿，选错时错误选项标红，并显示正确答案。
- 顶部实时显示 **第 X / N 题**、**得分** 和 **进度条**。
- 点「下一题」继续；全部完成后给出得分、评语，可「再来一次」。

### ✍️ 诗词填空

- 给出上句，在输入框补全下句。
- 作答时**自动忽略标点和空格**，写不写标点都算对。
- 按「确认」或 **回车** 提交；答错会显示正确答案与诗词出处。
- 顶部同样有得分与进度条，完成后可「再来一次」。

### 🖼️ 看图猜诗

分为两个难度，用顶部按钮切换：

- **简单**：看一组表情符号，从 4 个选项里选出对应的诗。
- **困难**：看一幅水墨画，自己在输入框写下**诗名或诗句**（任一皆可）。可点击：
  - **💡 提示**：显示提示句与作者；
  - **👀 看答案**：直接查看答案。

### 📖 诗词赏析

- 在搜索框输入 **诗名、作者或诗句** 关键词（例如 `李白`、`静夜思`、`举头望明月`）。
- 下方实时列出匹配结果（显示诗名、朝代·作者、首句）。
- **点击任意一首**即可展开查看 **原文、译文、赏析**，再点一次收起。

### 🌸 飞花令

- 先选一个**题目字**：花 / 月 / 风 / 春 / 雪 / 酒 / 山 / 水 / 人 / 云，或在下方的输入框**自选一个汉字**。
- 选择**先后手**：「你先」或「电脑先」。
- 你和电脑轮流说出**含这个字**的诗句，电脑会从内置诗词库中出句。
- 规则：
  - 诗句中**不含**所选字，或**重复**已说过的句子，都算失败；
  - 谁接不上，谁就输。
- 对局日志会记录双方每一句及其出处，顶部显示回合数。
- 可用「🔄 重新开始」重开一局，或「🏳️ 认输」结束对局。

## 技术说明

- **纯前端单文件**：`古诗词问答.html`，HTML + CSS + 原生 JavaScript，零依赖。
- **离线可用**：所有题库、赏析内容都内嵌在文件中，不请求任何外部资源。
- **题库可扩展**：诗词赏析与飞花令共用一个内置诗词库；新增题目只需在文件内对应数组（`quizData` / `fillData` / `emojiData` / `emojiHardData` / `poemExtra`）中追加即可。
